# FieldData Challenge

Task management system built with React, TypeScript, Tailwind CSS, and Vite.

## Requirements

- Node.js 18+
- pnpm (recommended) or npm

## Installation

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

The app will be available at `http://localhost:5173`

## Build

```bash
# Production build
pnpm build

# Preview build
pnpm preview
```
